# Data-Cleaning-Project
Cleaned and organized raw data in Excel by removing duplicates, correcting errors, handling missing values, and standardizing formats for accurate analysis.
Overview

This project demonstrates a comprehensive data cleaning process using Microsoft Excel. Raw datasets often contain inconsistencies, missing values, and formatting issues that can affect the quality of analysis. The goal of this project is to transform a messy dataset into a clean, structured, and analysis-ready format.

Key Tasks Performed

Duplicate Removal: Identified and removed duplicate records to ensure data uniqueness.

Error Correction: Fixed common data entry errors such as typos, incorrect formats, and invalid values.

Handling Missing Values: Used logical methods to fill, flag, or remove missing entries depending on context.

Standardization: Applied consistent formatting for text (e.g., case correction), numbers, and dates.

Purpose

Clean data is essential for accurate data analysis, visualization, and decision-making. This project is useful for anyone learning data cleaning techniques or preparing datasets for further use in Excel analytics.
